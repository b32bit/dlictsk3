# dlictsk3

อินโฟกราฟิกเชิงโต้ตอบสำหรับ **กลุ่มส่งเสริมการศึกษาทางไกล เทคโนโลยีสารสนเทศและการสื่อสาร**  
สำนักงานเขตพื้นที่การศึกษาประถมศึกษาสงขลา เขต 3

## ที่มาของข้อมูล

ข้อมูลและโครงสร้างภารกิจในโครงการนี้นำ **“คู่มือกลุ่มส่งเสริมการจัดการศึกษา ฉบับปรับปรุง พ.ศ. 2568”** มาเป็นข้อมูลอ้างอิงหลัก แล้วนำมาวิเคราะห์และจัดโครงสร้างใหม่ให้สอดคล้องกับ **ภาระงาน ระบบสารสนเทศ ระบบ/กิจกรรม และกลไกสนับสนุน** ที่ปฏิบัติงานจริง

การแสดงผลจึงเป็นการ **วิเคราะห์และจัดความสัมพันธ์ของข้อมูล** ไม่ใช่การคัดลอกโครงสร้างจากคู่มือมาแสดงทั้งหมดโดยตรง

## หลักการวิเคราะห์

โครงสร้างหลักของเว็บไซต์ใช้แนวคิด:

**22 ภารกิจหลัก → ระบบ / กิจกรรม / กลไกสนับสนุน → ผลลัพธ์ / การให้บริการ**

โดยแยกให้ชัดเจนว่า

- **ภารกิจหลัก** คือขอบเขตความรับผิดชอบตามโครงสร้างงาน
- **ระบบ / กิจกรรม / กลไก** คือเครื่องมือ กระบวนการ หรือกิจกรรมที่ใช้สนับสนุนการดำเนินภารกิจ
- ความสัมพันธ์เป็นแบบ **หลายต่อหลาย (Many-to-Many)** คือระบบหนึ่งสามารถสนับสนุนหลายภารกิจ และภารกิจหนึ่งสามารถมีหลายระบบหรือกิจกรรมสนับสนุน

## โครงสร้างเว็บไซต์

- `index.html` — หน้าอินโฟกราฟิกและ Dashboard แบบ Interactive
- GitHub Pages — ใช้เผยแพร่เว็บไซต์แบบ Static Web
- Tailwind CSS — ใช้จัดรูปแบบส่วนติดต่อผู้ใช้
- Chart.js — ใช้แสดงกราฟวิเคราะห์ข้อมูล

## การแสดงความสัมพันธ์

ในส่วน **“แผนผังความสัมพันธ์ ภารกิจ → ระบบ/กิจกรรม”**

- ตัวเลขในวงเล็บ เช่น **(12, 15)** แสดงภารกิจที่ระบบหรือกิจกรรมนั้นสอดคล้อง
- เมื่อคลิกกล่อง จะขยายเพื่อแสดง **ชื่อภารกิจเต็ม**
- รูปแบบนี้ช่วยให้เห็นภาพรวมได้รวดเร็ว และยังตรวจสอบรายละเอียดของแต่ละความสัมพันธ์ได้

## หมายเหตุ

การจัดกลุ่มและการเชื่อมโยงระบบ/กิจกรรมกับภารกิจเป็นผลจากการวิเคราะห์ภาระงานของกลุ่มงาน โดยควรใช้คู่มือและเอกสารราชการฉบับจริงเป็นแหล่งอ้างอิงเมื่อมีการนำข้อมูลไปใช้ในเอกสารทางราชการหรือการกำหนดหน้าที่อย่างเป็นทางการ
